# BARNES Newsletter CTA

Отдельный адаптивный CTA-блок для подписки на рассылку BARNES Moscow.

## Состав

- `index.html` — разметка блока и демонстрационная валидация формы;
- `styles.css` — стили desktop и mobile;
- `assets/` — изображения журнала BARNES для разных экранов.

Откройте `index.html` в браузере, чтобы посмотреть блок локально.
